# RE-Report Rubric (0-5 per axis)

## Axes
1. **Technical correctness**
   - 0: incorrect
   - 3: mostly correct with minor ambiguity
   - 5: precise, assumptions explicit
2. **Evidence quality**
   - 0: claims unsupported
   - 3: partial support
   - 5: strong claim-evidence chain
3. **Narrative clarity**
   - 0: confusing order
   - 3: understandable but rough transitions
   - 5: clean progressive model-building
4. **Graph fitness**
   - 0: decorative/misleading
   - 3: mostly useful
   - 5: each figure answers a concrete question
5. **Risk communication**
   - 0: hype/vague
   - 3: impact described with some caveats
   - 5: boundary/preconditions/limits explicit
6. **Actionability**
   - 0: no remediation path
   - 3: generic advice
   - 5: concrete mitigation + verification path
7. **Readability for non-specialists**
   - 0: jargon-heavy, hard to follow
   - 3: understandable with effort
   - 5: plain-English summary + clear decision guidance

## Pass criteria
- No axis < 3
- Technical correctness >= 4
- Evidence quality >= 4
- Graph fitness >= 4
- Readability for non-specialists >= 4 for mixed/executive audiences

## Final score
`Total / 35` and short fail reasons.
