# Extracted Style Notes (Consolidated)

## Model blend to use
- **Structure:** Quarkslab style (architecture -> root cause -> impact).
- **Readability:** Bits Please (method blocks, plain transitions).
- **Exploit chain narration:** BlackHat case-study rhythm.
- **Driver grammar precision:** Quarkslab MediaTek autopsy.

## Writing rules
1. Claim -> evidence -> interpretation in same local block.
2. One paragraph, one idea.
3. Always state tested scope and unknowns.
4. Prefer boundary-based severity language.

## Figure rules
- Add a figure only when it reduces simulation burden.
- Captions must state "what to notice".
- Keep global color semantics stable (e.g., red=vulnerable, green=patched).

## Graph planning handoff
Use `GRAPH_SPEC` blocks and implement rendering in python-scripting skill.
